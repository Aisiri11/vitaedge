# VitaEdge — Offline AI Health Triage Assistant

VitaEdge is an AI-powered offline healthcare triage assistant designed for rural healthcare workers and low-resource environments.

## Features

- AI-powered symptom analysis
- Urgency classification
- Explainable reasoning
- Confidence scoring
- Referral recommendations
- Offline-first concept

## Tech Stack

- Python
- Gradio
- Hugging Face Spaces
- Google Gemma
- Transformers
- Unsloth
